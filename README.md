# 班级云库 · 网络工程技术（本）2502班

广西农业职业技术大学网络工程技术（本）2502 班的班级资源门户。纯静态、单文件、无后端，上传到 GitHub 开 Pages 就能用。

## 它是什么

一个「索引」，不是「仓库」。

- 45 位同学的 WPS 独立文件夹 + 1 个班级共享云库，按姓名、学号、端口序号检索
- 学校 7 个官方入口（智慧学工、资源访问控制、SSL VPN、官网、两个 FTP 节点等）
- 从学校资源访问控制系统抄录的 22 个校内资源系统目录

页面里没有任何文档正文、附件、成绩数据。文件全部仍在学校 WPS 云文档里，谁能打开由 WPS 的分享权限决定。班委调权限不用改代码，WPS 里点几下即时生效。

## 目录结构

```
.
├── index.html    # 全部页面、样式、数据、逻辑（单文件，约 58 KB）
├── 404.html      # 路径不存在时回首页
├── robots.txt    # 禁止搜索引擎收录
├── .nojekyll     # 关闭 Jekyll，保证文件原样发布
├── .gitignore
└── README.md
```

`index.html` 自包含，单独把这个文件发给别人也能双击打开用，不依赖 `assets/` 或任何外部 CDN。

## 部署到 GitHub Pages

1. 新建仓库，建议命名 `class-cloud-2502`（公开仓库才能免费用 Pages）。
2. 把本文件夹里的全部文件上传到仓库根目录。注意 `.nojekyll`、`.gitignore` 是点开头的隐藏文件，网页版上传时要从文件管理器全选拖拽，否则会被漏掉。
3. 打开 **Settings → Pages**，Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，Save。
4. 等 1～2 分钟，访问 `https://<你的用户名>.github.io/class-cloud-2502/`。
5. 后续更新直接在 GitHub 网页上编辑 `index.html` 并提交，Pages 自动重新发布，链接不变。

仓库名必须小写、用连字符。用户名或仓库名改了，访问地址也会跟着变，届时需要重发二维码。

## 日常维护

改动都在 `index.html` 末尾的脚本区，两处：

```js
// 1) 访问口令
const GATE_CODE = "2502";

// 2) 名册
const MEMBERS = [
  { no:"2531020210201", name:"王苏子明", slug:"ctWvsvDFbsPW" },
  // ...
];
```

- **加人**：照抄一行，改学号、姓名、`slug`。`slug` 取自 WPS 文件夹链接 `https://www.kdocs.cn/folder/xxxx` 里的 `xxxx` 那段。排序、检索、计数、顶部刻度条都会自动重算，不用改别处。
- **删人**：删掉对应一行即可。
- **换口令**：改 `GATE_CODE`。注意它写在源码里，只能挡住随手点开的人，不是真正的鉴权。
- **改学校入口**：`PORTALS`（官方入口）与 `RESOURCES`（校内资源目录）两个数组，格式照现有条目。
- `RESOURCES` 里带 `…` 的系统名，是原页面显示不全的截断，没有补全，不要凭猜改全名。

## 先说清楚的三件事

**一、公开仓库等于公开名册。** GitHub Pages 免费版只能挂公开仓库，任何人拿到链接都能看到 45 位同学的姓名、学号和 WPS 文件夹地址。页面已经做了三道遮挡：`noindex` 阻止搜索引擎收录、口令门挡住随手点开的人、学号脱敏开关。但这三道都不是安全措施。

如果班级不接受这种暴露，两条更稳的路：

- 用学校提供的主机或教育网空间托管，做真实登录鉴权；
- 名册只留「序号 + 姓名」，学号不入库，靠姓名定位。

文档本身不因网页公开而泄露，因为点开链接后 WPS 还会校验账号权限。

**二、内嵌预览大概率是空白。** WPS 和校内系统普遍设置了禁止外部页面嵌套（`X-Frame-Options` / `frame-ancestors`），这是对方的安全策略，无法绕过。页面把内嵌预览定位为「顺手看一眼」，真正的阅览与编辑始终在 WPS 里完成，这样权限也始终由 WPS 把关。

**三、FTP 不能用浏览器打开。** Chrome、Edge、Firefox 都已移除 `ftp://` 协议支持，点了没反应是正常的。点一下会复制地址，粘贴到 Windows 资源管理器地址栏或 FileZilla 里用，且必须在校内网。

## 校内资源目录的用法

那 22 条不直连域名，原因很简单：校外只能通过资源访问控制系统的代理进内网。正确路径是

1. 打开 `https://vpn.gxnzd.com.cn/login` 登录；
2. 在站内「资源站点」里点对应系统；
3. 校园网内则可以直接把域名补成 `https://` 访问，内网 IP 那几条通常是 `http://` 加端口。

目录里有两组重复地址（`172.16.5.70`、`10.0.100.33`），是原页面本来就这样，不是抄错。

## 技术说明

- 原生 JavaScript，无框架、无构建、无 `type="module"`，`file://` 双击可用
- 数据固化在脚本里而不是 `fetch` JSON，因为 `file://` 下不能读本地文件
- 移动端优先设计，断点 640 / 1024
- 页内 hash 路由：`#/home`、`#/library`、`#/portal`、`#/access`、`#/maint`
- 状态存在 `localStorage`：`cl_access_v1`（口令状态）、`cl_access_v1_mask`（脱敏开关）
- 不用 emoji，图标为内联 SVG
