两个对话实验

这里的页面都是纯静态 HTML，跑不了模型本身：一个把界面接到外部接口的算力，一个把模型下载到本机浏览器里跑。两者互不依赖，是收在主站「更多 → 高级功能」里的旁路实验，不承担班级办事责任。

云端 API

云端对话实验

界面通过 OpenAI 兼容接口调用外部模型。可走自己的代理（Key 留服务器），也可在页面里自填地址、模型和 Key（只存本机）。

  • 多轮上下文，最近 10 条一起送
  • 对话记录只存本机浏览器，可导出 JSON
  • 公开仓库页面不要填长期 Key
打开云端对话 → 浏览器本地推理

本地推理实验

模型权重下载到本机浏览器，推理在设备上完成，对话不上传。Transformers.js + WebGPU，不支持时自动退回 WASM。

  • 可选 0.5B 轻量 / 1.5B 推理型两个 ONNX 模型
  • 首次下载后缓存本地，第二次不再重复下
  • 吃硬件：建议 Chrome / Edge，独显或较强核显
打开本地推理 → 站外演示 · Wasm Linux

Unkernel 浏览器内 Linux（官方 demo）

真实 Linux 内核编译成单个 WebAssembly 模块，浏览器标签页里约一秒进到 shell；Alpine / Debian 软件包可直接装，改动存在本机浏览器。本站只给外链入口，不托管、不留存它的会话。

  • 官方演示站 unkernel.dev，首下约 10MB；Chrome / Edge / Safari / Firefox 可开
  • 开源：SDK 与页面 MIT，内核 GPL-2.0；源码 github.com/pithings/unkernel
  • 仅作技术对照体验；自托管需可发隔离头的托管与自建代理，前置条件未凑齐，不在本站接入
