# ai-lab · 对话实验与站外演示

纯静态 HTML 实验目录，与班级云库主站互不依赖。页面本身跑不了大模型，只做界面：一个接外部接口的算力，一个把模型下载到本机浏览器推理；另附一张站外官方演示外链，本站不托管。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 目录入口：两张站内实验卡片 + 一张 Unkernel 站外演示外链卡 |
| `cloud-chat.html` | 云端 API 对话：OpenAI 兼容接口，代理 / 直连两种模式可切 |
| `local-chat.html` | 浏览器本地推理：Transformers.js，WebGPU 优先、WASM 降级 |

## 云端对话（cloud-chat.html）

- **代理模式（推荐）**：默认已填班级站那台腾讯云开发函数的 `/proxy/chat` 地址，Key 留在服务器环境变量，页面碰不到密钥；可在设置里改成自己的代理。
- **直连模式**：页面里填 `base_url`、模型名、API Key，存在本机 `localStorage`（键 `lab_cloud_v1`），不写进代码。
- 兼容 OpenAI `/chat/completions` 格式；若浏览器报 CORS 跨域错误，说明该厂商不允许网页直连，改走代理模式。
- **流式输出**：直连模式带 `stream:true` 解析 SSE，增量逐字写到气泡；代理模式后端是一次性返回（未做 SSE 透传），整段出现，属预期差异。
- **图片识图（仅直连）**：直连模式输入框旁可附一张图，前端压到最长边 1280、JPEG 后按 OpenAI `image_url` 视觉格式随消息发出；能否看懂取决于所接模型是否为多模态（VL）。代理后端契约只收文本、本地浏览器也跑不动 VLM，这两条线不开放附件入口。
- 代理有来源闸：只放行 `medianigray.github.io` 等白名单 origin，本机 `127.0.0.1` 起服务调试会被 403，验证请走线上 Pages；每来源每天 40 次上限，消息服务端再截最近 6 条、每条 400 字。
- 对话历史存在本机 `localStorage`（键 `lab_cloud_hist_v1`，最近 30 条），刷新页面后保留，可导出 JSON；带入上下文的历史轮数可在设置里选最近 5 / 10 / 20 轮（默认 10）。切换接入方式或模型后旧对话仍保留作上下文，需要全新对话点「清空对话」。图片占本地配额，存盘超限时只保留文字、丢弃图片。
- 每条助手回复带「复制」「朗读」「重新生成」：朗读走浏览器本机语音合成（Web Speech），不调云端；设置抽屉里可选本机中文音色（女声排前、标注男女声）、试听、调语速与音调；失败时点重新生成即重试最近一轮，成功后可重答替换原回复。外观可在设置里调字号三档（小 / 标准 / 大）、底色三档（奶油纸 / 米白 / 雾灰）、密度两档（舒适 / 紧凑）、强调色九预设（墨绿 / 靛蓝 / 青灰 / 藏青 / 陶棕 / 暖橘 / 豆沙红 / 酱紫 / 抹茶）加自定义取色，均随设置存本机、开机即套。

### Key 红线

公开仓库的页面**不能写死长期 Key**：任何人查看源码都能拿走烧额度。直连模式的 Key 只存在使用者自己的浏览器里；要给多人用，一律走代理，Key 放服务端环境变量。

## 本地推理（local-chat.html）

- 运行库：`@huggingface/transformers@4.3.1`，jsDelivr ESM 引入。
- 可选模型（均为 ONNX 仓库）：
  - `onnx-community/Qwen2.5-0.5B-Instruct`：约 400 MB，核显 / 轻薄本更稳。
  - `onnx-community/DeepSeek-R1-Distill-Qwen-1.5B-ONNX`：约 1 GB，推理型带思考过程，建议 WebGPU 独显或较强核显。
- 下载源可切国内镜像 `hf-mirror.com` 或 Hugging Face 官方；权重缓存到浏览器本地，第二次打开不再重复下载。
- 设备：`navigator.gpu` 可用走 WebGPU，失败自动退回 WASM（CPU，明显变慢）。
- 生成参数：温度、最大生成字数、带入上下文的历史轮数（最近 5 / 10 / 20 轮，默认 10）、system 预设词可在设置里改，存本机 `localStorage`（键 `lab_local_v1`）。
- 对话历史同样存在本机 `localStorage`（键 `lab_local_hist_v1`，最近 30 条），刷新页面后保留，可导出 JSON；清空对话会一并清掉本地留存。
- 切换模型或下载源后，已加载的旧模型会释放，下次提问重新加载；旧对话仍保留作上下文，需要全新对话点「清空对话」。
- **流式输出**：用 Transformers.js `TextStreamer` 回调逐 token 累加，增量清洗后写到气泡；收尾以完整生成文本为准覆写。
- 助手回复同样带「复制」「朗读」「重新生成」：朗读走浏览器本机语音合成，推理仍在本机；音色、语速、音调、字号、底色、密度、强调色档位与云端页一致；本地模型空回复或跑题时，可基于最近一轮重新推理替换。

### 硬件与体验约束

- 浏览器：Chrome / Edge 对 WebGPU 支持最好；Safari / Firefox 可能只能走 WASM。
- 手机能跑但速度有限；7B 及以上量化模型在浏览器里不现实。
- 小模型容易答得简短或跑题，属模型能力限制，不是页面故障。
- 首次加载要下载权重，页面会显示进度；清浏览器数据会连同缓存一起删掉，下次需重新下载。

## 站外演示（外链 · Unkernel）

- 目录页另有一张跨列外链卡，指向 Unkernel 官方演示站 `https://unkernel.dev`：真实 Linux 内核编译成单个 WebAssembly 模块，浏览器标签页里约一秒进到 shell，Alpine / Debian 软件包可直接装，改动存在本机浏览器。
- 首下约 10MB，Chrome / Edge / Safari / Firefox 可开；开源，SDK 与页面 MIT，内核 GPL-2.0，源码 `github.com/pithings/unkernel`。
- 本站只给外链入口，不托管、不留存它的账号、文件与会话。自托管需可发隔离头的托管、自建代理、可达 CDN 镜像与兼容检测，前置条件凑齐前不在本站接入。

## 场景模板 chips

两页输入框上方各有一排场景快捷入口，覆盖十类常见用途：软件开发、网页自动化、文件整理、文字创作、投资研究、办公文档、调研检索、事务效率、数据洞察、多模态创作。

- 点一下即把对应角色预设（system）写入设置，并在输入框填入一句示例问题，可再编辑后发送。
- 入口列表可在设置抽屉按行增删改（每行一条标签，留空回落默认，最多 12 条），存本机、重开回填；沿用内置名称的条目仍带对应角色预设，自填条目只把文字填进输入框、不改预设词。
- 这是「入口先有、能力靠模型」的弱实现：模板只定角色与口径，真正回答仍走云端接口或本机模型；投资、数据、多模态等类别在纯静态页里不接专用工具，只给提示词与思路，不替代专业渠道。
- 预设词可在设置抽屉里改；改动后不再与任一模板一致，高亮自动取消。

## 人设一键预设

设置抽屉的 system 预设词上方有一排人设档位：默认（回落内置默认预设词）、答疑助手、简短口语、严谨正式。点一下即把对应 system 文本填入预设词框并即时存本机，当前档位高亮；再手改预设词后不再与任一预设一致，高亮自动取消。场景模板 chips 切换角色后，预设档位高亮同步刷新。文案为通用实验口径，不绑定班级门户场景。

## 部署到 GitHub Pages

三个文件都是静态文件，放进仓库根目录或子目录即可，无需构建。注意：

- 本地推理页的模型权重**不进仓库**，首次打开从所选下载源拉取并缓存。
- 直连模式填的 Key 只在使用者本机，不要把填过 Key 的页面源码提交上去。
- `file://` 双击打开时部分浏览器对 WebGPU / 缓存有限制，建议用本地静态服务或部署到 `https` 后再测。

## 实测状态

- 已在浏览器验证：目录入口、两页控件回填与模式切换、空态移除、发送/清空/导出/复制接线、失败兜底（本地校验与网络错误都能在气泡里给出提示并恢复输入）、WebGPU 探测与 WASM 降级分支、控制台无脚本报错。
- 流式接线已落地：云端直连 SSE 逐段解析、本地 `TextStreamer` 回调逐字渲染；已确认 `transformers@4.3.1` 正常导出 `TextStreamer`，两页本地起服务加载控制台无报错，内联脚本通过 `node --check`。
- 历史轮数档位（5 / 10 / 20）已在两页设置抽屉接线，选择后写入 `localStorage`、重开抽屉正确回填；本地切换模型后状态栏提示旧模型将释放重载、旧对话保留，控制台无报错。
- 对话历史本机留存已接线：两页启动从 `localStorage` 回填最近 30 条，发送/重试更新/清空都会写回；浏览器实测预置历史刷新后正确回填、清空后存盘为空数组，控制台无报错。云端页与本地页均可「导出对话 JSON」，Blob 下载含导出时间与历史快照。
- 场景 chips 本机可编辑已接线：设置抽屉 textarea 每行一条标签，输入即解析（去空、最多 12 条）写入 `localStorage` 并重渲染；留空回落内置十类；内置名称匹配到的条目点击仍套角色预设，自填条目只填文字。重开抽屉按当前列表回填。
- 助手气泡「朗读」按钮已接线，走浏览器 `speechSynthesis`，取本机中文语音、缺省回退 `zh-CN`；浏览器不支持语音合成时按钮自动不出现。设置抽屉可音色下拉（女声优先排序、标注男女声）、试听、语速（0.6–1.6）、音调（0.6–1.6，默认 1.25），随配置存本机并重开回填；字号小 / 标准 / 大三档（zoom 0.92 / 1 / 1.09），开机即套不跳变。本测试环境无中文语音包、无头引擎未真正出声，仅验证调用路径不抛错、页面无报错；实际朗读效果以本机浏览器可用语音为准。
- 底色三档（奶油纸 / 米白 / 雾灰）与密度两档（舒适 / 紧凑）已在两页设置抽屉接线：切换即换纸面色系变量或紧凑间距，写入 `localStorage`、重开抽屉回填，head 内联脚本开机即套避免刷新跳变；内联脚本通过 `node --check`。
- 强调色已在两页接线：九预设色点一键切换按钮、选中态与重点标记，另附自定义取色器；选预设或取色后由基色派生浅色 / 深色三档变量，写入 `localStorage`、重开抽屉回填当前色与取色值，head 内联脚本开机即套；内联脚本通过 `node --check`。
- 人设一键预设已在两页接线：四个档位（默认 / 答疑助手 / 简短口语 / 严谨正式）点击即写 system 预设词并存本机、当前档高亮；默认档在预设词回落到内置默认时高亮；手改后高亮取消，场景 chips 切换后同步刷新；内联脚本通过 `node --check`。
- 图片附件仅在云端直连模式出现：浏览器实测选图后经 canvas 压成 JPEG dataURL、缩略图预览与移除均正常，切回代理模式附件入口隐藏并清掉待发图；控制台无报错。真实看图效果需所接 VL 模型与允许网页跨域的接口在线上 origin 验证。
- 本地模型的**权重真实下载与出回复**未在本测试环境跑通：该环境到 `hf-mirror.com` / `huggingface.co` 不可达（`Failed to fetch`），jsDelivr CDN 正常；本地流式的真实逐字效果需在能访问模型源的网络下首开验证。换到能访问所选下载源的网络后，首次打开本地页按提示下载即可；浏览器支持 WebGPU 走独显，不支持自动退回 WASM。
- 云端页代理模式已在线上 Pages 实测连通：默认班级站云函数代理，测试连接正常返回；直连模式 SSE 逐字效果需自填允许网页跨域的接口与 Key 后在线上 origin 验证；代理模式后端一次性返回，整段出现。

## 这一版没做的

- 代理模式 SSE 透传：云函数 `/proxy/chat` 仍一次性返回整段，代理线拿不到流式增量；要让代理也逐字，需后端改成流式转发。
- 代理与本地识图：代理后端只收文本、浏览器端跑不动 VLM，附件入口只在云端直连开放；云端 TTS（调厂商语音接口）、模型权重离线打包进仓库。本机朗读用浏览器自带语音合成，不在此项内。
- 对话跨设备同步（按隐私口径，记录只留本机）。
- Unkernel / Wasm Linux 自托管：目录页仅留官方 demo 外链；本站不内嵌、不部署内核镜像，隔离头托管与代理前置条件凑齐再议。
