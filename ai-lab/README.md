# ai-lab · 两个对话实验

纯静态 HTML 实验目录，与班级云库主站互不依赖。页面本身跑不了大模型，只做界面：一个接外部接口的算力，一个把模型下载到本机浏览器推理。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 目录入口，两张卡片分别进下面两页 |
| `cloud-chat.html` | 云端 API 对话：OpenAI 兼容接口，代理 / 直连两种模式可切 |
| `local-chat.html` | 浏览器本地推理：Transformers.js，WebGPU 优先、WASM 降级 |

## 云端对话（cloud-chat.html）

- **代理模式（推荐）**：默认已填班级站那台腾讯云开发函数的 `/proxy/chat` 地址，Key 留在服务器环境变量，页面碰不到密钥；可在设置里改成自己的代理。
- **直连模式**：页面里填 `base_url`、模型名、API Key，存在本机 `localStorage`（键 `lab_cloud_v1`），不写进代码。
- 兼容 OpenAI `/chat/completions` 格式；若浏览器报 CORS 跨域错误，说明该厂商不允许网页直连，改走代理模式。
- **流式输出**：直连模式带 `stream:true` 解析 SSE，增量逐字写到气泡；代理模式后端是一次性返回（未做 SSE 透传），整段出现，属预期差异。
- 代理有来源闸：只放行 `medianigray.github.io` 等白名单 origin，本机 `127.0.0.1` 起服务调试会被 403，验证请走线上 Pages；每来源每天 40 次上限，消息服务端再截最近 6 条、每条 400 字。
- 对话历史只存本机，可导出 JSON；最近 10 条一起送模型。
- 每条助手回复带「复制」和「重新生成」：失败时点重新生成即重试最近一轮，成功后可重答替换原回复。

### Key 红线

公开仓库的页面**不能写死长期 Key**：任何人查看源码都能拿走烧额度。直连模式的 Key 只存在使用者自己的浏览器里；要给多人用，一律走代理，Key 放服务端环境变量。

## 本地推理（local-chat.html）

- 运行库：`@huggingface/transformers@4.3.1`，jsDelivr ESM 引入。
- 可选模型（均为 ONNX 仓库）：
  - `onnx-community/Qwen2.5-0.5B-Instruct`：约 400 MB，核显 / 轻薄本更稳。
  - `onnx-community/DeepSeek-R1-Distill-Qwen-1.5B-ONNX`：约 1 GB，推理型带思考过程，建议 WebGPU 独显或较强核显。
- 下载源可切国内镜像 `hf-mirror.com` 或 Hugging Face 官方；权重缓存到浏览器本地，第二次打开不再重复下载。
- 设备：`navigator.gpu` 可用走 WebGPU，失败自动退回 WASM（CPU，明显变慢）。
- 生成参数：温度、最大生成字数、system 预设词可在设置里改，存本机 `localStorage`（键 `lab_local_v1`）。
- **流式输出**：用 Transformers.js `TextStreamer` 回调逐 token 累加，增量清洗后写到气泡；收尾以完整生成文本为准覆写。
- 助手回复同样带「复制」「重新生成」：本地模型空回复或跑题时，可基于最近一轮重新推理替换。

### 硬件与体验约束

- 浏览器：Chrome / Edge 对 WebGPU 支持最好；Safari / Firefox 可能只能走 WASM。
- 手机能跑但速度有限；7B 及以上量化模型在浏览器里不现实。
- 小模型容易答得简短或跑题，属模型能力限制，不是页面故障。
- 首次加载要下载权重，页面会显示进度；清浏览器数据会连同缓存一起删掉，下次需重新下载。

## 场景模板 chips

两页输入框上方各有一排场景快捷入口，覆盖十类常见用途：软件开发、网页自动化、文件整理、文字创作、投资研究、办公文档、调研检索、事务效率、数据洞察、多模态创作。

- 点一下即把对应角色预设（system）写入设置，并在输入框填入一句示例问题，可再编辑后发送。
- 这是「入口先有、能力靠模型」的弱实现：模板只定角色与口径，真正回答仍走云端接口或本机模型；投资、数据、多模态等类别在纯静态页里不接专用工具，只给提示词与思路，不替代专业渠道。
- 预设词可在设置抽屉里改；改动后不再与任一模板一致，高亮自动取消。

## 部署到 GitHub Pages

三个文件都是静态文件，放进仓库根目录或子目录即可，无需构建。注意：

- 本地推理页的模型权重**不进仓库**，首次打开从所选下载源拉取并缓存。
- 直连模式填的 Key 只在使用者本机，不要把填过 Key 的页面源码提交上去。
- `file://` 双击打开时部分浏览器对 WebGPU / 缓存有限制，建议用本地静态服务或部署到 `https` 后再测。

## 实测状态

- 已在浏览器验证：目录入口、两页控件回填与模式切换、空态移除、发送/清空/导出/复制接线、失败兜底（本地校验与网络错误都能在气泡里给出提示并恢复输入）、WebGPU 探测与 WASM 降级分支、控制台无脚本报错。
- 流式接线已落地：云端直连 SSE 逐段解析、本地 `TextStreamer` 回调逐字渲染；已确认 `transformers@4.3.1` 正常导出 `TextStreamer`，两页本地起服务加载控制台无报错，内联脚本通过 `node --check`。
- 本地模型的**权重真实下载与出回复**未在本测试环境跑通：该环境到 `hf-mirror.com` / `huggingface.co` 不可达（`Failed to fetch`），jsDelivr CDN 正常；本地流式的真实逐字效果需在能访问模型源的网络下首开验证。换到能访问所选下载源的网络后，首次打开本地页按提示下载即可；浏览器支持 WebGPU 走独显，不支持自动退回 WASM。
- 云端页代理模式已在线上 Pages 实测连通：默认班级站云函数代理，测试连接正常返回；直连模式 SSE 逐字效果需自填允许网页跨域的接口与 Key 后在线上 origin 验证；代理模式后端一次性返回，整段出现。

## 这一版没做的

- 代理模式 SSE 透传：云函数 `/proxy/chat` 仍一次性返回整段，代理线拿不到流式增量；要让代理也逐字，需后端改成流式转发。
- 多模态识图、云端 TTS、模型权重离线打包进仓库。
- 对话跨设备同步（按隐私口径，记录只留本机）。
