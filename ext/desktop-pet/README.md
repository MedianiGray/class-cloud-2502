# 班级云库 · 大肥鱼桌宠（浏览器扩展）

## 它解决什么

门户里的大肥鱼桌宠原本只挂在班级云库网页内，离开站点就看不到。这个 MV3 扩展把同一只大肥鱼挂到**任意网页**的左下角：可拖动、摸头、喂食、聊两句，台词走本地内置池，不接 AI 定时调用。

素材（webm 动画）复用门户线上 Pages 地址，扩展包本身不带 8.7 MB 视频；离线或线上素材不可达时鱼不显示，不影响页面本身。

## 安装（一次性，1 分钟）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions/`（Edge 为 `edge://extensions/`）回车
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序 / 加载未打包的扩展程序」，选中本文件夹（`desktop-pet`）
4. 扩展栏出现即成功，可固定到工具栏

> 本扩展未提交浏览器商店，只能以开发者模式加载；换电脑需重新加载一次。上架 Chrome / Edge 商店所需账号、费用、材料与主体口径，见门户 `ROADMAP.md`「开发者认证与代码签名准备」小节。

## 用法

- 打开任意网页，大肥鱼出现在左下角
- 单击摸头 / 互动，拖拽可移动位置，喂食、内置聊天窗随库自带
- 门户站内（`medianigray.github.io/class-cloud-2502`）已有原生鱼，扩展自动跳过，不会一条页面挂两条
- 想移除：扩展页点「移除」即可

## 边界

- 只做陪伴展示，不读取页面内容、不收集数据；台词好感度按站点本地存，跨网站不共享
- 动画素材来自门户线上目录，依赖网络；无网络时不显示动画
- 库为 MAIN 世界注入，遵循页面自身的脚本策略；个别强 CSP 站点可能注入失败，失败不影响该页面
- **只支持桌面 Chrome / Edge**：手机上的 Chrome、Edge、Safari 都不支持加载第三方扩展（无开发者模式入口），本扩展不在移动端使用；手机端要看鱼，进站网页内自带小尺寸鱼，或按门户「装到主屏」加成 PWA
- 角色为 DeepSeek 蓝鲸社区二创，非官方形象；仅作班级非教学场景内陪伴展示，不商用、不宣称官方

## 文件

- `manifest.json` — 扩展声明，MV3（含 `icons` 与工具栏 `action` 图标）
- `content.js` — 隔离世界引导：写素材基址配置、按序注入库与启动脚本；站内已有原生鱼时跳过
- `init.js` — 主世界启动：读配置后调 `Dafeiyu.mount(...)` 把鱼挂到左下角
- `dafeiyu.iife.js` — 桌宠库（与门户 `pet/dafeiyu.iife.js` 同源副本）
- `icons/` — 16 / 48 / 128 三档 PNG 图标（当前为动画抽帧占位，正式视觉可替换）
- `screenshots/` — 商店截图占位图（上架前在干净浏览器 + 普通页面重拍正式图）

## 打包成 zip（分发给本机他人时）

在 `ext/` 目录下把 `desktop-pet/` 文件夹整体压缩为 `desktop-pet.zip`（manifest.json 位于压缩包根目录，不要多套一层文件夹）；他人解压后按上面「安装」步骤加载解压目录即可。
