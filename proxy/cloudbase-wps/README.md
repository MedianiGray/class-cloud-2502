# 换端代理 · 部署到腾讯云开发（免费额度那条路）

这一份是给「桌面浏览器想看 WPS 移动版」用的中转。原来那个 Cloudflare Worker 版在 `proxy/wps-proxy.js`，逻辑一样，但对国内不可用 —— 不是代码问题，是 `workers.dev` 这个域名被 DNS 污染，实测解析十七毫秒就返回、连接立刻超时。所以换到云开发，它的域名 `*.tcloudbaseapp.com` 国内直连。

## 先看清「不会花钱」是怎么保证的

云开发对个人开发者有一份长期免费额度，这类低流量代理用不到零头。但有几个地方是真会扣钱的，部署时看到这些就停手：

| 看到什么 | 要怎么做 |
|---|---|
| 「升级套餐」「按量付费」 | 不点。留在免费档 |
| 「绑定支付方式」「充值」 | 不绑。绑了才有扣费通道 |
| 「购买独立域名」「CDN 加速」 | 不买。用平台自带的 `*.tcloudbaseapp.com` |
| 「实名认证」 | **这个要做**。实名不等于付费，它只是国内云服务的合规要求 |

额度用尽的正常表现是「当天调用被限流」，不是扣钱。真到那一步，页面会打不开，不会账单上门。

## 五步部署

1. 打开 <https://tcb.cloud.tencent.com>，微信或 QQ 扫码登录，按提示做实名
2. 新建环境，套餐选**免费**那一档。记下环境 ID，形如 `prod-1a2b3c`
3. 进「云函数」→ 新建函数 → 名字 `wps` → 运行时 `Node.js 18`
   把本目录 `index.js` 的全部内容粘进去，保存并部署
4. 进这个函数的「HTTP 访问服务」→ 添加路径 `/wps` → 指向函数 `wps`
5. 记下完整地址，形如 `https://prod-1a2b3c.tcloudbaseapp.com/wps`

## 接回页面

打开 `index.html`，找到这一行（搜索「换端代理」能定位）：

```js
const PROXY = "";   /* 填上第 5 步那个地址，测试两个字就能摘掉 */
```

把地址填进去，然后：

- 按钮上现在带「测试」两个字，点了会用这个地址去取移动版
- 能正常翻目录、能开预览，就把按钮文案里的「测试」去掉
- 如果报超时或空白，先自己 curl 一次看看：`curl "https://.../wps?u=https%3A%2F%2Fwww.kdocs.cn%2Ffolder%2FceMSyJ9Ww4NJ&mode=phone"`，返回 HTML 且带 `mShare` 就说明通了

## 已知边界（不会有变化）

- 只对**公开分享链接**有效。要登录才看的文档，代理没有你的账号态
- 能看、能翻目录、能开预览；上传、编辑这类写操作不行
- 只放行 `kdocs.cn`，不会被当成任意网站的开放代理
- 代理不保存任何内容，也不转发你的账号密码

## 如果这条也走不通

备选是阿里云函数计算，形态几乎一样，改 `exports.main` 的入口写法即可。不再往下试 Vercel / Netlify —— 它们的免费域名在国内也是时通时不通，属于同一类问题。
