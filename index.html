网页与文档的关系

这套网页只做索引、指引和问答，不存文档正文。GitHub Pages 上只有匿名端口目录和链接，没有任何姓名、完整学号、文档正文、附件或成绩数据。真正的访问控制发生在 WPS：成员点开链接后，WPS 会先校验他的账号与权限，没权限的人看到的只是一张「无权访问」的提示。因此就算网页链接被转发出去，文件本身也不会泄露。

这也是这套结构能长期用的原因：调整权限不用改代码，在 WPS 里点几下就行；网页不需要维护数据。

06 · 手机看电脑版 / 电脑看手机版不用装东西，浏览器自己就能切

WPS 给你哪套界面，只看你浏览器报上去的身份（User-Agent）。网页没有权限改它 —— 这是浏览器的硬限制，任何网站都做不到，所以「在页面上点一下换界面」这种按钮不可能真的生效。

能做的是让浏览器自己去说。对照你正在用的环境，一次设好，之后一直有效：

  • 手机 · 微信或 QQ 里点开的：内置浏览器没有桌面版开关。先点右上角「…」→「在浏览器打开」，跳到 Chrome、Edge 或夸克；再到那个浏览器的菜单里勾「请求桌面网站 / 电脑版网页」，刷新即可。
  • 手机 · Chrome、Edge、夸克、UC：打开菜单（Chrome 是地址栏右边的 ⋮）→ 勾上「桌面版网站 / Desktop site」→ 刷新。关掉开关就回到手机版。
  • 电脑 · Chrome、Edge 想看成手机版：按 F12，再按 Ctrl + Shift + M，顶部会出现设备框，左边选 iPhone 或安卓机型，刷新一下。关掉开发者工具就恢复原样。
  • 电脑 · Firefox：按 Ctrl + Shift + M 进响应式设计模式，顶部选机型即可。

这些开关都在浏览器里，本站一个都碰不到，也不会记录你的设置。预览窗口里那颗「换端」只按你当前设备给对应做法，不会假装切换——换端要在服务端改 User-Agent，我们试过用云端代取，能拿到手机版的壳但文件列表是空的，所以没启用。想看真移动版，点地址栏右边 ▣ 扫码，手机打开就是 WPS 给的移动版。

三、内嵌预览为什么可能空白

「尝试内嵌预览」是在页面里用 iframe 打开 WPS 链接。WPS 与多数校内系统都设置了禁止外部页面嵌套的安全策略，这时预览区会显示拒绝或空白——这是对方的安全设置，不是页面故障，也无法绕过。遇到这种情况点「在 WPS 中打开」，浏览器新标签页里正常访问。

所以本页把内嵌预览定位为「顺手看一眼」，真正的阅览与编辑始终在 WPS 里完成，这样权限校验也始终由 WPS 负责。

四、公开仓库的隐私问题

GitHub Pages 免费版只能挂公开仓库，任何人都能打开这个网址、也能在仓库里看到源码。所以名册里不存完整学号：45 人的学号一律只保留后三位，完整学号只存在于班级 WPS 云库。除此之外还有两层降低暴露的手段：noindex 阻止搜索引擎收录、口令门挡住随手点开的人——这两层都不是真正的安全措施，只是降低被随手翻到的概率。

如果还想更稳：① 用学校服务器或教育网空间托管（可做真实鉴权）；② 现在名册已经只保留「序号 + 尾号」，连姓名都没有；若连尾号也不想露，把 no 清空、只按端口序号对人即可。文档本身的权限是安全的，因为文件都在 WPS 里。

五、给评奖评优留的位置

这套结构先把「材料归位」做掉，评优就不靠临时翻聊天记录。建议每学期在共享库里固定四类目录：01 通知归档 / 02 集体荣誉 / 03 个人材料 / 04 申报汇总；个人证书扫描件各人放进自己的独立文件夹。学期末班委只需打开总目录，逐人核对即可，不必再逐个私聊收材料。

文档库　班级 WPS 共享文件夹。成员链接收在脚本里的 MEMBERS，只存尾号，不存姓名与完整学号；文件本身始终在 WPS，权限由 WPS 把关。

10
首页「记住我是谁」　只把学号后三位存在本机 localStorage 的 cl-seat-no 键里，不上传、不写进页面。换设备要重输一次；改这个键名，全班同学的记忆都会失效。清掉的办法：把输入框改成自己的学号再点一次「打开」。
11
首页那只「大肥鱼」　开源网页宠物 dafeiyu（MIT），动画素材来自 dsh-pet（MIT），角色是 DeepSeek 蓝鲸的社区二创、非官方。脚本和 20 个动画都在本站 pet/ 目录（约 8.7 MB），不走外部 CDN——CDN 那条线路拉 400 KB 的视频会卡死，宠物二十秒后就自己退出了。页面静下来两秒后才加载；prefers-reduced-motion 下不加载。嫌它动：右键菜单点「睡觉」；想彻底去掉，删掉首页末尾那段宠物脚本即可，别动别处。素材别放进 sw.js 的缓存清单，9 MB 进 Cache API 会让首次访问多写一遍盘——sw.js 里已按 /pet/ 跳过。手机上也出现，尺寸按视口分三档（118 / 146 / 210），并给它的视频补了 touch-action:none：不补这条，手指一压浏览器先当滚动，拖动会被 pointercancel 打断，表现就是一挪就闪、松手跳位、点一下点空。小助手面板开着时鱼会被 visibility:hidden 让位，关掉再回来。
12
联网兜底的云端函数（可选）　双击桌宠直接打开右下角「问问」卡片；桌宠自己的碎碎念仍只说本机台词，不接 AI。「问问」的联网兜底走云端函数 proxy/tcb/index.js。模型 Key 只能存在函数环境变量里，绝不能填进页面——公开仓库写进来等于谁都能拿去烧额度。函数带了四道闸：只认班级站来源、每来源每天 40 次、历史 6 条每条 400 字、输出 240 tokens。别给桌宠碎碎念接 AI，那是定时自动说一句，接上就是定时烧额度，台词留在本地池。
13
右下角「问问」是个能动手的 agent　它不只是答话，手里有五样活：切分区（h 路由）、开外链（o）、复制地址（c）、跑一段函数（do）、按学号直接开那一格（说了三位数就认）。规则在 RULES 数组里，一条就是「关键词 + 回答 + 动作」，a 可以写成函数，这样它能报「你现在在哪、这区有几个入口」这种活信息。规则全没命中时会去 RESOURCES 和 PORTALS 里真搜一遍，搜到就给可点的按钮，不会一句「没学会」把人推回班群。别给它加写操作——它能读能跳能开，但不能替任何人改任何东西，这条线守住，坏不了事。宠物那边它调的是 window.__PET，能说话、能换动作、能收走；宠物没加载时按钮会明确说它不在这儿，不假装成功。
14
桌宠只挂大肥鱼这一只有完整动画的形象　它是第三方开源库（MIT），骨骼加物理的那种，二十段真动画，能拖、能摸头、右键喂饭和下五子棋。早先的静态 PNG 贴纸（pet/shapes/*@480.png）和五只逐帧精灵图都已从选择列表撤下，素材文件保留在目录里没删；精灵图来自 github.com/legeling/awesome-codex-pet，素材 CC BY-NC 4.0。想再加形象，要接骨骼动画或 Live2D 素材，单张 PNG 不再进选择列表；目标形象清单、每个形象的素材状态与协议核对见根目录 PET-ROSTER.md。这里有个坑，别再踩：大肥鱼被 destroy() 之后重建不出来（实测切回就是 no-host），所以它只挂一次，隐藏时只 display:none；也别去扒 B 站那种 Live2D 公皮，作者明确禁止盗用。切换一句 __PET_SWITCH("dafeiyu")，可用 id 看 __PET_LIST()，选过的记在 cl_pet_shape_v2。

01

九、更新 Worker：一条命令，别用网页编辑器

Cloudflare 的在线编辑器是嵌在跨域 iframe 里的 Monaco，自动粘贴进不去，手贴 150 行也容易漏行。改完 proxy/wps-proxy.js 直接用 API 传，最稳。

# 1) 建 Token：dash.cloudflare.com/profile/api-tokens → Create Token # → Start from scratch → Account policy → Workers Scripts: Edit → 有效期选 7 days # Token 只显示一次，用完立刻 Delete $acc = "9b541232809822d0a0af2a7150310e47" $tok = "<刚才那个 Token>" $f = "proxy\wps-proxy.js" $meta = "$env:TEMP\cf-meta.json" $json = '{"body_part":"worker.js","compatibility_date":"2025-01-01"}' [IO.File]::WriteAllText($meta, $json, (New-Object System.Text.UTF8Encoding -ArgumentList $false)) C:\Windows\system32\curl.exe -sS -X PUT "https://api.cloudflare.com/client/v4/accounts/$acc/workers/scripts/cl-wps-proxy" -H "Authorization: Bearer $tok" -F "metadata=@$meta;type=application/json" -F "worker.js=@$f;type=application/javascript"

返回 "success": true 就是上线了。四个坑，按顺序都可能踩到：

01
别用「Edit Cloudflare Workers」模板建 Token。它带一条 Zone policy，而班级账号名下没有域名，会卡在 Choose a zone resource 出不来。用 Start from scratch 只勾 Account → Workers Scripts: Edit。
02
metadata 必须走文件。写成 -F 'metadata={"main_module":"worker.js"}' 会被 PowerShell 剥掉内层引号，服务端报 invalid character 'm' looking for beginning of object key string。
03
别写 main_module，源码里也别出现 export default。这个 Worker 是 classic 类型，带了就报 Unexpected token 'export'。所以脚本用的是 addEventListener("fetch", ...) + 顶层 async function handleRequest，改代码时保持这个结构。
04
curl 要写全路径。PowerShell 里 curl 是 Invoke-WebRequest 的别名，写法不同会静默失败；一律用 C:\Windows\system32\curl.exe。

十、最容易出问题的六个地方

01
WPS 改版。代理靠的是 WPS「服务端按 UA 分两套壳」这个行为，它一改目录结构，代理可能只返回壳、内容出不来。自查一行：
$h = @{ "User-Agent" = "…iPhone…" }; $r = Invoke-WebRequest "https://www.kdocs.cn/folder/<slug>" -Headers $h -UseBasicParsing; $r.RawContentLength; ($r.Content -match 'mShareFolder')
返回 5000 字节上下、mShareFolder 为真 → 分流还在；变成登录页或 2000 字节左右 → 手机壳入口变了。
02
Worker 免费额度。每天 10 万请求，班级规模一年用不到百分之一。别把白名单 HOSTS 扩大，否则它会变成公开代理，额度很快烧完还可能被封。
03
WPS 限流。同一个分享页被反复代理抓，可能触发风控返回验证页。Worker 里给的是 cache-control: max-age=30，别改成 0。真被限流时把 PROXY 临时清空即可——退回 ▣ 扫码，不影响任何人看文档。
04
分享被撤回。写着「永久有效」也会被分享者收回。撤回后代理拿到的是 WPS 的错误页，不是站点坏了，别去改代码。
05
PWA 装不上。按顺序排查：当前是不是 https（file:// 一定不行）→ 是不是在微信 / QQ 内置浏览器（装不了，先「在浏览器打开」）→ DevTools → Application → Service Workers → Unregister 清掉旧壳再试。
06
全班都还看到旧版。把 sw.js 里的 CACHE = "class-cloud-2502-v1" 改成 v2 再推，activate 阶段会清掉旧缓存。

十一、换端不用服务器

结论已经定下来：WPS 按请求头 UA 分两套壳，而 UA 只有浏览器自己能改，所以换端是浏览器的本地功能，本站不掺和。预览窗口右上角那颗「换端」只按当前设备给一句对应做法，不加载任何代理页、也不假装切换。

代理这条线试过并已停用：云函数能取到手机版的 HTML 壳，但取文件列表的接口对服务端请求回空，页面里翻不出东西；*.workers.dev 在国内被 DNS 污染；Deno 停注册；Netlify 新站带访问保护；*.vercel.app 解析不出。页面已不再调用 /proxy/wps，那条路由留在云函数里也不产生流量和费用。

十二、出事了先做这一句

页面是单文件，改坏了直接回退，别在原地抢救：

git checkout HEAD~1 -- index.html git commit -m "revert index.html" git push

回退后等 1–2 分钟，带 ?t=随机数 打开确认。确认好了再慢慢找原因——站点始终可用，比「修好」更重要。
